# Open-source project architecture analyses

This directory contains source-level architecture notes for the repositories under `../open/`.
Each project analysis should cite repository paths and explain the documentation coverage,
architecture, runtime flow, state/data model, key files, extension points, and trade-offs.

## Repositories

- agentscope
- autogen
- crewAI
- deepseek-harness
- deer-flow
- hermes-agent
- langgraph
- llama_index
- pydantic-ai

## Coverage policy

Repositories contain thousands of Markdown files, including localized copies, historical
versioned docs, generated reference pages, and skill/example documentation. Analyses must
inventory these files, identify duplicate/localized/historical groups, and explicitly list
which documentation sets were read. Do not claim every Markdown file was read unless the
coverage ledger confirms it. Source claims must be checked against implementation files.
